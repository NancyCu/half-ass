# 80/20 Half Marathon Training PWA

A mobile-first Vite + React + TypeScript PWA for a 15-week 80/20 half marathon plan. The first screen answers: what am I running today, how hard, and what pace?

## Run It

```bash
npm install
npm run dev
```

## Build

```bash
npm run lint
npm run build
```
